# CSS Challenge

## Objective
Three focused CSS exercises for the WeIntern Web Development Internship (Week 1, Task 3): a Flexbox layout, a CSS Grid layout and a set of subtle animations.

## Tech stack
HTML5, CSS3 (Flexbox, Grid, transitions, keyframes) and a few lines of vanilla JavaScript for the animation replay button.

## What is implemented
- **Flexbox:** three equal-height cards in a row using `justify-content`, `align-items`, `gap` and `flex`; they stack below 700px; hover lift effect.
- **Grid:** seven dashboard tiles on `repeat(4, 1fr)`, reflowing to two columns (960px) and one column (560px); the first tile spans two columns.
- **Animation:** animated underline link, button fill sweep, loading spinner and staggered fade-in. No absolute positioning; reduced-motion supported.
