# Business Landing Page: Rootline Physiotherapy

## Objective
A responsive landing page for a fictional physiotherapy clinic, built for the WeIntern Web Development Internship (Week 1, Task 2). It follows the sequence problem, value, services, trust, action.

## Tech stack
HTML5 (semantic), CSS3 (custom properties, Flexbox, Grid), vanilla JavaScript.

## Features
- Sticky navigation with brand, section links and a "Book now" call to action
- Hero with value proposition, primary and secondary buttons, and a first-visit card
- Six service cards in a responsive grid, patient testimonials
- Contact form with name, email, phone and message, using HTML validation plus JavaScript checks
- Mobile menu below 768px, touch-friendly 44px+ controls, visible focus states, reduced-motion support
