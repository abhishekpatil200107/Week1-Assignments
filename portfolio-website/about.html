About me

I'm a web development intern at WeIntern Pvt Ltd, building responsive websites with HTML, CSS and JavaScript. I started with small static pages and now build multi-page sites with layouts that adapt from phones to wide desktops.

I like the point where design meets code: choosing spacing, type and colour so a page is easy to read, then writing markup that a screen reader can follow just as easily.
