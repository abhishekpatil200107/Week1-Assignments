# Portfolio Website

## Objective
A responsive, multi-page portfolio for a frontend developer, built for the WeIntern Web Development Internship (Week 1, Task 1).

## Tech stack
HTML5 (semantic), CSS3 (custom properties, Flexbox, Grid), vanilla JavaScript. No frameworks or UI libraries.

## Features
- Home, About, Projects and Contact pages with consistent navigation
- Mobile-first responsive layout with a collapsing mobile menu
- Dark / light mode toggle (remembers your choice)
- Project filtering by category
- Smooth scrolling, visible focus states, skip link, reduced-motion support
- Contact form with HTML validation

## Folder structure
```
portfolio-website/
├── index.html
├── about.html
├── projects.html
├── contact.html
├── css/style.css
├── js/script.js
├── assets/images/
├── assets/icons/

```

## Run locally
Open `index.html` in a browser, or serve the folder with `npx serve` or the VS Code Live Server extension.
